【제목】
스마트스토어 AI 자동답글

【짧은 설명】(132자 이내)
리뷰·문의가 쌓여도 하나씩 쓰지 마세요. 내 기존 답글 말투로 초안을 만들고, 판매자센터 답변란에 채워 줍니다.

【상세 설명】
스마트스토어 리뷰·문의, 밤마다 하나씩 답장하고 계신가요.

쌓인 리뷰와 상품문의를 가져와서, 사장님이 이미 쓴 답글의 말투로 초안을 만듭니다. 확인한 뒤 판매자센터 답변란에 채워 넣을 수 있습니다. 답글을 복붙하고 고치느라 새는 시간을 줄이려고 만든 확장입니다.

카카오 로그인만 하면 답글 10건은 무료로 써 볼 수 있습니다.

이렇게 씁니다
1. 판매자센터에서 리뷰나 상품문의를 엽니다
2. 확장에서 목록을 가져옵니다
3. 예전에 단 답글로 말투를 한 번 맞춥니다
4. 초안을 확인하고, 답변란에 채웁니다

이런 분께 맞습니다
· 리뷰·문의가 매일 쌓이는 스마트스토어 판매자
· 답글은 달고 싶은데, 말투가 들쭉날쭉한 게 싫은 분
· 본인 스토어의 리뷰·문의만 처리하는 분

요금
· 무료 체험: 답글 10건, 말투 맞추기 1회
· 베이직 월 9,900원: 답글 150건
· 스탠다드 월 19,900원: 답글 600건
· 프로 월 39,900원: 답글 2,000건

구독은 30일입니다. 해지하면 만료일까지 쓸 수 있고, 다음 결제는 없습니다.

────────────────────────────────────────
구독은 토스페이먼츠 카드 자동결제(빌링)로 등록됩니다.
플랜 업그레이드는 차액 결제, 다운그레이드는 만료일부터 전환 예약할 수 있습니다.
구독 취소 시 만료일까지 이용 가능하며 자동결제는 중단됩니다.
자세한 안내: billing-terms.html

■ 권한 사유 (심사·Privacy practices)
────────────────────────────────────────

  storage
    로그인 세션, 답글 작업·말투 설정 저장

  tabs
    답글 만들기·스타일 선택 작업 탭 열기, 기존 탭 포커스

  scripting
    판매자센터 페이지에 콘텐츠 스크립트 주입

  notifications
    답글 생성·작업 완료 알림

  sidePanel
    확장 아이콘 클릭 시 사이드 패널로 설정·답글 작업 화면을 엽니다.
    판매자센터 탭을 가리지 않고 리뷰·문의 답글 초안을 확인·수정하기 위해 사용합니다.

  host: sell.smartstore.naver.com
    판매자 본인 스토어 리뷰·문의 조회 및 답변란 입력 보조

  host: naver-smartstore-review-reply-production.up.railway.app
    회원 로그인, AI 답글 API, 구독·사용량 확인

  page-hook.js (web_accessible_resources)
    판매자센터에서 리뷰 검색 API URL을 찾기 위해, 해당 페이지의
    fetch/XHR만 후킹합니다. 다른 사이트·타인 데이터는 접근하지 않습니다.

■ Host permission justification (영문)

  This extension helps Naver Smart Store sellers draft and submit review
  and product inquiry replies. It only runs on sell.smartstore.naver.com
  and communicates with our API server for login, AI generation, and
  subscription. page-hook.js intercepts network requests on the seller
  center page solely to discover review API endpoints for the logged-in
  seller's own store.

■ 데이터 수집 (Privacy practices)

  수집: 이메일, 카카오 ID(선택), 리뷰·문의 텍스트, 답글 초안, 구독·결제 정보
  용도: AI 답글 생성, 구독 관리
  제3자: Google Gemini, Kakao OAuth, Toss Payments, Railway hosting
  정책 URL: (위 privacy.html)
