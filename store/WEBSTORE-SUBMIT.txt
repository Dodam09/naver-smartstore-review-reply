■ 스토어 등록 절차
  1. Chrome Web Store Developer Dashboard → 새 항목
  2. ZIP 업로드
  3. 가시성: 「비공개(Unlisted)」 — 링크 있는 사람만 설치
  4. 개인정보: 「개인 식별 정보를 수집함」 체크
  5. 개인정보 처리방침 URL 입력 (위 URL)
  6. 단일 목적(Single purpose): 스마트스토어 판매자 리뷰·상품문의 답글 보조

■ 스토어 설명 (복사용 초안)

  제목: 스마트스토어 답글 도우미 — AI 리뷰·문의 답글

  짧은 설명:
  네이버 스마트스토어 리뷰·상품문의 답글을 AI로 만들고 판매자센터에 올립니다.

  상세 설명:
  · 네이버 스마트스토어 판매자센터(sell.smartstore.naver.com) 전용
  · 리뷰·상품문의 목록 가져오기 → AI 답글 초안 → 검토 후 입력란 채우기·등록
  · 판매자 말투(프롬프트) 설정·분석 지원
  · 계정 로그인 후 구독 플랜 이용 (베타: 테스트 결제)
  · AI 처리는 운영 서버를 통해 Google Gemini API 사용
  · 구독·결제는 확장 밖 웹 페이지(토스페이먼츠)에서 처리

  베타 안내 문구(현재 mock 결제일 때):
  현재 베타 기간이며 테스트 결제로 이용합니다. 실제 카드 청구는 없습니다.

■ 권한 사유 (심사·Privacy practices)

  storage
    로그인 세션, 답글 작업·말투 설정 저장

  tabs
    답글 만들기·스타일 선택 작업 탭 열기, 기존 탭 포커스

  scripting
    판매자센터 페이지에 콘텐츠 스크립트 주입

  host: sell.smartstore.naver.com
    판매자 본인 스토어 리뷰·문의 조회 및 답글 입력 보조

  host: naver-smartstore-review-reply-production.up.railway.app
    회원 로그인, AI 답글 API, 구독·사용량 확인

  page-hook.js (web_accessible_resources)
    판매자센터에서 리뷰 검색 API URL을 찾기 위해, 해당 페이지의
    fetch/XHR만 후킹합니다. 다른 사이트·타인 데이터는 접근하지 않습니다.

■ Host permission justification (영문, 필요 시)

  This extension helps Naver Smart Store sellers draft and submit review
  and product inquiry replies. It only runs on sell.smartstore.naver.com
  and communicates with our API server for login, AI generation, and
  subscription. page-hook.js intercepts network requests on the seller
  center page solely to discover review API endpoints for the logged-in
  seller's own store.

■ 데이터 수집 (Privacy practices)

  수집: 이메일, 카카오 ID(선택), 리뷰·문의 텍스트, 답글 초안, 구독·결제 정보
  용도: AI 답글 생성, 구독 관리
  제3자: Google Gemini, Kakao OAuth, Toss Payments, Railway hosting
  정책 URL: (위 privacy.html)

■ 업데이트 방법 (중요)
  로컬 코드 수정만으로 스토어에 반영되지 않습니다.
  1. manifest.json version 올리기 (예: 1.3.20 → 1.3.21)
  2. store/manifest.json 도 동일 버전으로 수정
  3. .\scripts\package-store.ps1
  4. Developer Dashboard → 새 ZIP 업로드 → 심사 제출
  5. 승인 후 사용자 Chrome이 자동 업데이트 (수 시간~수 일)
