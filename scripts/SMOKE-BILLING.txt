# 결제 연결 후 수동 스모크 체크리스트
# health.productionReady=true 확인된 뒤에 진행하세요.
# .\scripts\verify-billing-ready.ps1

확장 [설정] → 로그인 → [구독하기]

[ ] 1. 신규 구독
    - 플랜 「결제하기」 → 토스 카드 등록(빌링)
    - 계정 요약에 플랜·만료일·자동갱신 표시
    - 결제 내역에 신규 구독 1건

[ ] 2. 업그레이드
    - 더 높은 플랜 → 차액 결제
    - 만료일 유지·플랜명 변경

[ ] 3. 다운그레이드 예약
    - 낮은 플랜 → 「만료일부터 ○○로 예약」(결제창 없음)
    - [다운그레이드 예약 취소]로 철회 가능

[ ] 4. 구독 취소 / 철회
    - 확장 [구독 취소] → 만료까지 이용·자동결제 중단
    - [취소 철회] → 자동갱신 복구

[ ] 5. (선택) 관리자 /admin.html 에서 구독·주문 상태 확인

테스트 키(test_ck/test_sk)면 토스 테스트 카드 사용.
라이브 키면 소액 실청구 후 필요 시 환불.
