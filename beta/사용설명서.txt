스마트스토어 답글 도우미 — 사용 설명서 (베타 v1.3.20)
====================================================


1. 이 프로그램이 하는 일
-----------------------

· 네이버 스마트스토어 리뷰·상품문의를 가져옵니다.
· AI가 판매자 말투에 맞춰 답글 초안을 만듭니다.
· 판매자센터 답글 입력란에 자동으로 채우거나, 한 번에 등록할 수 있습니다.

베타 버전은 서버에 로그인한 뒤 이용합니다. (확장에 API 키 입력 불필요)


2. 화면 구성
------------

확장 팝업 상단 탭 3개:

  [리뷰]        리뷰 답글 작업
  [상품문의]    문의 답글 작업
  [계정]        로그인, 구독, 작업 초기화

리뷰·문의 탭 안에는 상단 모드 2개:

  [답변할 댓글 가져오기]   목록 불러오기 → 답글 만들기로 이동
  [답변 스타일 설정]       AI 말투(프롬프트) 설정

그 아래 「적용 중인 AI 지침」 배너:
  · 지금 답글에 실제로 쓰이는 AI 지침 전문이 보입니다.
  · [변경 →] 누르면 스타일 설정으로 이동합니다.


3. 계정 · 구독
--------------

[계정] 탭

  · 카카오 로그인 또는 이메일 가입/로그인
  · [구독하기] — 베타는 「테스트 결제」(실제 카드 청구 없음)
  · 플랜별 답글·말투 분석 횟수 한도 있음
  · [저장된 작업 모두 지우기]
      → 가져온 목록, 만든 답글, 진행 중 작업만 삭제
      → 로그인, 구독, 말투 설정은 유지


4. 답변 스타일 설정
-------------------

말투 방식은 네 가지 중 하나만 적용됩니다.
마지막에 선택·저장한 방식이 답글에 사용됩니다.

  (1) 기존 답글로 만들기 ★ 추천
      [기존 답글로 내 말투 만들기] → 새 창에서 답글 2~3개 선택
      → AI가 말투 분석
      → 분석된 지침은 카드 안에서 바로 수정 가능

  (2) 답글 붙여넣기
      예전 답글 2개 이상 붙여넣기 → [붙여넣은 답글로 말투 만들기]
      엑셀/메모 양식 업로드 가능

  (3) 프리셋
      기본 제공 말투 목록에서 선택

  (4) 직접 지침
      AI에게 줄 지시문을 직접 작성

카드 헤더를 누르면 해당 방식이 선택됩니다.
선택된 카드만 펼쳐지고, 배지에 「적용 중」「설정 완료」 등이 표시됩니다.


5. 리뷰 답글 — 단계별
---------------------

【준비】
  · sell.smartstore.naver.com 로그인
  · 리뷰 관리 페이지 열기

【1단계 · 가져오기】
  확장 [리뷰] → [답변할 댓글 가져오기]
  · 기간 선택 → [가져오기]
  · 또는 「엑셀 파일로 가져오기」
  · 완료 후 [다음: 답글 만들기]

【2단계 · 답글 만들기】
  · [답글 만들기 시작] → 답글 만들기 창(새 탭)
  · 이미 창이 열려 있으면 그 창으로 이동 (중복 방지)

  답글 만들기 창:
  ┌─ 선택 탭 ─────────────────────────┐
  │  답글 달 리뷰 체크                  │
  │  [AI로 답글 만들기]                 │
  └────────────────────────────────────┘
  ┌─ 검토 탭 ─────────────────────────┐
  │  AI 답글 확인·수정                  │
  │  [잠깐 저장]        — 초안만 저장   │
  │  [판매자센터에 채우기 준비]         │
  │  [한 번에 올리기]                   │
  └────────────────────────────────────┘

【3단계 · 판매자센터 적용】
  · 「채우기 준비」 후: 리뷰 답글 칸 열면 자동 입력
  · 「한 번에 올리기」: 확장이 API로 일괄 등록 시도
  · 내용 확인 후 반드시 직접 [등록] 확인

상품문의도 [상품문의] 탭에서 동일한 흐름입니다.


6. 버튼 차이 (답글 만들기 창)
------------------------------

  잠깐 저장
    · 검토 중 수정 내용을 브라우저에 저장
    · 창을 닫았다 열어도 이어서 작업 가능
    · 판매자센터 자동 채우기는 켜지지 않음
    · (입력 시 자동 저장도 됩니다)

  판매자센터에 채우기 준비
    · 모든 답글이 채워졌는지 검사
    · 준비 완료 시 판매자센터 답글 칸 자동 채우기 ON
    · 답글을 다시 고치면 다시 이 버튼을 눌러야 함

  한 번에 올리기
    · 판매자센터 API로 여러 답글 일괄 등록
    · 실패 시 메시지 확인 후 개별 등록


7. 문제 해결
------------

  증상                          확인할 것
  ─────────────────────────────────────────────────
  로그인 화면만 보임            [계정] 탭에서 로그인
  AI 사용 불가                  테스트 결제(구독) 완료 여부
  가져오기 실패                 판매자센터 로그인·해당 페이지
  자동 채우기 안 됨             「채우기 준비」 눌렀는지
  답글 만들기 창이 두 개        v1.3.20부터 하나만 유지됨
  말투가 이상함                 [답변 스타일 설정]에서 재설정

  오류 발생 시: 화면 캡처 + 단계 설명을 배포자에게 전달


8. 개인정보 · 보안 (베타)
-------------------------

  · 리뷰·문의 내용은 AI 답글 생성을 위해 서버·Google AI로 전송됩니다.
  · 베타 ZIP에는 API 키가 들어 있지 않습니다.
  · 판매자센터 로그인 비밀번호는 확장이 저장하지 않습니다.
  · 테스트용으로 지인에게만 ZIP을 공유해 주세요.
