스마트스토어 답글 도우미 — 베타 설치 (v1.3.20)
============================================

■ 배포 파일 두 가지

  A) naver-smartstore-reply-beta.zip  (배포자가 만든 베타 ZIP)
     → 압축만 풀면 됩니다. config.js 가 이미 들어 있습니다.

  B) GitHub 소스 ZIP
     → 압축 풴 뒤 3단계 config.js 복사가 필요합니다.


■ A) 베타 ZIP 설치 (지인 배포용)

  1) naver-smartstore-reply-beta.zip 압축 해제
  2) chrome://extensions → 개발자 모드 ON
  3) 「압축해제된 확장 프로그램을 로드합니다」
  4) 압축 푼 폴더(naver-smartstore-reply-beta) 선택
  5) beta/지인용-설치안내.txt 또는 beta/사용설명서.txt 참고


■ B) GitHub 소스 설치 (개발자용)

  1) GitHub → Code → Download ZIP
  2) 압축 해제
  3) beta/config.js 를 프로젝트 루트에 config.js 로 복사
     (manifest.json 과 같은 폴더)
  4) chrome://extensions → 개발자 모드 → 폴더 로드

  또는 PowerShell:
    scripts/package-beta.ps1
  → beta/dist/naver-smartstore-reply-beta.zip 생성 (A와 동일)


■ 베타 ZIP 다시 만들기 (배포자)

  PowerShell에서 프로젝트 루트:
    .\scripts\package-beta.ps1

  결과:
    beta/dist/naver-smartstore-reply-beta.zip
    beta/dist/naver-smartstore-reply-beta/   (폴더)


■ 첫 실행

  1) 확장 아이콘 고정
  2) [계정] 탭 → 카카오 또는 이메일 로그인
  3) [구독하기] → 테스트 결제 (실제 카드 결제 없음)
  4) [리뷰] 또는 [상품문의] 탭 사용

  ※ API 키 입력은 베타에서 필요 없습니다 (서버 연동).


■ 참고

  · 「개발자 확장 프로그램」 경고 → [확장 프로그램 관리] → [유지]
  · 상세 사용법: beta/사용설명서.txt
  · 문의: GitHub Issues 또는 배포자
