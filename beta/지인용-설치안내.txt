  스마트스토어 답글 도우미 — 베타 안내 (v1.3.20)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

안녕하세요!
리뷰·상품문의 답글을 AI로 만들고, 판매자센터에 올리는 도우미입니다.
아래 순서대로 진행해 주세요. (실제 돈은 나가지 않는 테스트 모드입니다.)


■ 준비물
  · Google Chrome
  · 네이버 스마트스토어 판매자센터 로그인
    (sell.smartstore.naver.com)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. 설치 (처음 한 번)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1) 받은 ZIP 압축 해제
2) Chrome 주소창 → chrome://extensions
3) 우측 상단 「개발자 모드」 켜기
4) 「압축해제된 확장 프로그램을 로드합니다」
5) 압축 푼 폴더 선택

※ 「개발자 확장 프로그램」 경고가 뜨면
   [확장 프로그램 관리] → [유지] 눌러 주세요.

6) Chrome 퍼즐 아이콘 → 「스마트스토어 답글 도우미」 고정


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  2. 로그인 · 구독 (처음 한 번)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1) 확장 아이콘 클릭 → [계정] 탭
2) 카카오 로그인 (또는 이메일 가입/로그인)
3) [구독하기] 클릭
4) 「위 정기결제 조건에 동의합니다」 체크
5) 원하는 플랜 → 「○○ 테스트 결제」
   → 카드 결제 없음, 테스트용입니다.

구독 전에는 AI 답글·말투 분석을 쓸 수 없습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  3. 말투 설정 (처음 한 번, 추천)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[리뷰] 또는 [상품문의] 탭 → 상단
  [답변 스타일 설정] 클릭

방법 4가지 중 하나만 선택합니다.

  ★ 기존 답글로 만들기 (추천)
     판매자센터에서 예전 답글 2~3개 고르기

  · 답글 붙여넣기
     예전에 쓴 답글을 직접 붙여넣어 분석

  · 프리셋
     기본 말투 중에서 고르기

  · 직접 지침
     AI에게 줄 문장을 직접 작성

상단 「적용 중인 AI 지침」에 지금 쓰는 말투가 보입니다.
답글을 만들 때 이 지침이 적용됩니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  4. 리뷰 답글 만들기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

① 판매자센터 준비
   sell.smartstore.naver.com → 리뷰 관리 페이지 열기

② 확장 → [리뷰] 탭 → [답변할 댓글 가져오기]
   기간 선택 → [가져오기]
   (또는 엑셀 파일로 가져오기)

③ [다음: 답글 만들기] → [답글 만들기 시작]
   → 새 탭(답글 만들기 창)이 열립니다.
   ※ 이미 열려 있으면 새 창 대신 그 창으로 이동합니다.

④ 답글 만들기 창
   · 리뷰 선택 → [AI로 답글 만들기]
   · [검토] 탭에서 답글 읽고 수정
   · [판매자센터에 채우기 준비]
     → 판매자센터에서 답글 칸을 열면 자동으로 채워짐
   · 또는 [한 번에 올리기]로 여러 건 등록

⑤ 판매자센터에서 각 리뷰 답글 칸 열기 → 자동 입력 확인 → 등록

  5. 상품문의 답글
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[상품문의] 탭에서 리뷰와 같은 순서입니다.
  가져오기 → 답글 만들기 → 검토 → 판매자센터 적용

Q. AI가 안 돼요
A. [계정]에서 로그인 + 테스트 결제(구독) 했는지 확인

Q. 가져오기가 안 돼요
A. 판매자센터에 로그인했는지, 리뷰/문의 페이지를 열었는지 확인

Q. 「잠깐 저장」은 뭐예요?
A. 검토 중인 답글을 임시 보관합니다.
   판매자센터 자동 채우기는
   [판매자센터에 채우기 준비]를 눌러야 켜집니다.

Q. 「저장된 작업 모두 지우기」는?
A. 가져온 목록·만든 답글·진행 작업만 지웁니다.
   로그인·구독·말투 설정은 그대로입니다.

Q. 오류가 나요
A. 화면 캡처 + 어떤 단계인지 알려 주세요.
