[스마트스토어 답글 도우미 — 베타 테스트 안내]

안녕하세요! 아래 순서대로 하시면 됩니다.
(실제 돈은 나가지 않는 테스트 모드입니다.)

■ 필요한 것
· Google Chrome 브라우저
· 네이버 스마트스토어 판매자센터 계정 (sell.smartstore.naver.com)

■ 1. 설치
1) 받은 ZIP 파일 압축 해제 (폴더 하나 생김)
2) Chrome 주소창에 chrome://extensions 입력
3) 우측 상단 「개발자 모드」 켜기
4) 「압축해제된 확장 프로그램을 로드합니다」 클릭
5) 압축 푼 폴더 선택

※ 「개발자 확장 프로그램」 경고가 뜨면 [확장 프로그램 관리] → [유지] 눌러 주세요.

■ 2. 로그인
1) Chrome 퍼즐 아이콘 → 「스마트스토어 답글 도우미」 고정
2) 확장 아이콘 클릭 → [설정] 탭
3) 카카오 로그인 (또는 이메일 가입)

■ 3. 구독 (테스트)
1) [설정] → [구독하기]
2) 「위 정기결제 조건에 동의합니다」 체크
3) 원하는 플랜 → 「○○ 테스트 결제」 클릭
   (카드 결제 없음, 테스트용입니다)

■ 4. 사용
1) 네이버 판매자센터(sell.smartstore.naver.com) 로그인
2) 확장 열기 → [리뷰] 또는 [상품문의] 탭
3) 기간 선택 → [판매자센터에서 가져오기] → 답글 생성

■ 문제 생기면
· 로그인/구독: 확장 [설정] 탭 상태 확인
· AI 안 됨: 구독(테스트 결제) 했는지 확인
· 오류 메시지 캡처해서 보내 주세요
