FAQ

자주 묻는 질문

설치와 이용 전에 궁금한 내용을 확인해 보세요.

답변이 판매자 확인 없이 자동 등록되나요?

아닙니다. AI가 답변 초안을 생성하면 내용을 확인하고 수정할 수 있습니다. 확인한 답변을 판매자센터 답변란에 입력하고 등록하는 방식입니다.

어떤 환경에서 사용할 수 있나요?

PC Chrome 브라우저에서 네이버 스마트스토어 판매자센터를 이용할 때 사용할 수 있습니다. 모바일 앱이나 다른 브라우저, 다른 쇼핑몰은 지원하지 않습니다.

무료 체험에 카드 등록이 필요한가요?

무료 체험은 계정당 1회 제공되며, 답변 초안 10건과 말투 맞추기 1회를 카드 등록 없이 이용할 수 있습니다. 유료 구독을 시작할 때는 카드 자동결제가 등록됩니다.

유료 구독은 어떻게 결제되고 해지하나요?

유료 플랜은 30일 단위 카드 자동결제로 갱신됩니다. 확장 프로그램의 [설정]에서 구독을 취소할 수 있으며, 취소하더라도 이미 결제된 이용 기간 만료일까지 사용할 수 있습니다. 자세한 내용은 구독·결제 안내를 확인해 주세요.

다른 판매자의 리뷰나 다른 쇼핑몰도 불러오나요?

아닙니다. 판매자가 로그인한 본인 스마트스토어의 리뷰와 상품문의를 답변 생성 목적으로 불러옵니다. 다른 판매자 계정이나 다른 쇼핑몰은 지원하지 않습니다.

로그인은 어떤 방식으로 하나요?

카카오 로그인 또는 이메일 로그인을 지원합니다.
