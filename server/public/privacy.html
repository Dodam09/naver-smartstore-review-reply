개인정보 처리방침

스마트스토어 답글 도우미 (Chrome 확장 프로그램 및 연동 서비스)

시행일: 2026년 8월 28일

1. 개요

본 방침은 「스마트스토어 답글 도우미」(이하 「서비스」)가 이용자의 개인정보를 어떻게 수집·이용·보관·파기하는지 설명합니다. 서비스는 네이버 스마트스토어 판매자가 본인 스토어의 리뷰·상품문의 답글 작성을 돕기 위해 제공됩니다.

2. 수집하는 정보

구분 항목 수집 경로
계정 이메일, 비밀번호(해시 저장), 카카오 로그인 식별값 회원가입·로그인
구독·결제 플랜, 구독 상태, 결제·환불 내역, 빌링키(토스페이먼츠 보관) 구독·결제 과정
서비스 이용 리뷰·상품문의 내용, 상품명, 답글 초안, 말투(프롬프트) 설정, 사용량(답글·말투 분석 횟수) 확장 프로그램 사용
기술 정보 접속 IP, 요청 시간, 오류 로그(최소한) 서버 접속 시

확장 프로그램은 판매자센터(sell.smartstore.naver.com)에서 판매자 본인이 조회·작성하는 데이터만 처리합니다. 구매자의 결제수단·주민등록번호 등은 수집하지 않습니다.

3. 이용 목적

  • 회원 식별, 로그인, 구독·요금제 관리
  • AI 답글·말투 분석 생성 및 사용 한도 관리
  • 판매자센터 답글 입력·등록 보조
  • 결제·환불·고객 문의 처리
  • 서비스 안정성·보안 유지

4. AI 처리 및 제3자 제공

  • 답글 생성·말투 분석을 위해 리뷰·문의·답글 샘플 텍스트가 Google Gemini API로 전송될 수 있습니다. (모델: gemini-2.5-flash 등, 서버를 통해 호출)
  • 로그인: 카카오 OAuth (카카오 로그인 선택 시)
  • 결제: 토스페이먼츠 (카드 정보는 당사 서버에 저장하지 않음)
  • 호스팅: Railway (회원·구독 DB 및 API 서버)

위 목적 외 제3자에게 개인정보를 판매하거나 제공하지 않습니다. 법령에 따른 요청이 있는 경우는 예외입니다.

5. Chrome 확장 프로그램 권한

  • storage: 로그인 세션, 작업 중인 답글·설정 저장
  • tabs / scripting: 답글 작업 탭 열기·포커스, 판매자센터 페이지 연동
  • sell.smartstore.naver.com: 리뷰·문의 가져오기 및 답글 입력 보조
  • page-hook.js: 판매자센터에서 본인 스토어 API URL을 찾기 위해 페이지 내 네트워크 요청을 후킹합니다. 타 사이트·타인 데이터는 접근하지 않습니다.
  • API 서버: 로그인·AI·구독 처리 (Railway)

6. 보관 기간

  • 회원·구독 정보: 회원 탈퇴 또는 구독 종료 후 관리자 정책에 따라 삭제 (지체 없이 처리 원칙)
  • 확장 프로그램 로컬 저장: 이용자 기기에서 [저장된 작업 모두 지우기] 또는 확장 삭제 시 삭제
  • 결제 기록: 전자상거래·세법 등 관련 법령에 따른 기간

7. 이용자 권리

  • 확장 [계정] 탭에서 로그인·구독 취소·작업 데이터 삭제 가능
  • 회원 정보 열람·정정·삭제 요청: 아래 문의처로 연락

8. 안전 조치

  • 비밀번호 해시 저장, HTTPS 통신
  • API 인증 토큰 사용, 관리자 페이지 별도 보호
  • Gemini API 키는 서버에만 보관 (확장에 포함하지 않음)

9. 만 14세 미만

서비스는 스마트스토어 판매자(사업자·성인)를 대상으로 하며, 만 14세 미만 아동을 대상으로 하지 않습니다.

10. 방침 변경

내용 변경 시 본 페이지에 게시하며, 중요한 변경은 서비스 내 안내할 수 있습니다.
